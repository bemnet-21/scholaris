# Scholaris — Frontend

The web presentation layer for **Scholaris: Intelligent Autonomous Literature & Fact Engine**, built with React 19, TypeScript, Tailwind CSS v4, and Vite.

## Features

- **Dark Academia Scholarly Aesthetic**: Deep obsidian tones, warm gold accents, and serif typography.
- **Dynamic 5-Stage Pipeline Tracker**: Visualizes decomposition, source routing, multi-source retrieval, critique, and synthesis in real time.
- **Academic Report Viewer**: Clean, formatted academic document display with inline citation pills and source reference cards.
- **Scholar Authentication**: Session management with instant guest scholar enrollment or email/passphrase login.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev
```

The app will start on `http://localhost:3000`. By default, API requests are proxied to `http://127.0.0.1:8000`.
